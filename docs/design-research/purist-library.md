# Purist (https://purist.design/library)

## What it is
A library of tunable motion components you can take to the canvas or via MCP. New components drop weekly. Each component ships with HTML/CSS/React code that you can inspect, tune, and copy. Focus on real-use motion, not experimental demos.

## Free or paid
Free to browse and use the library components. Sign-in required to copy code, but no explicit paid tier mentioned for the library itself. Download and MCP access available.

## Steal for CotizaIA
- Radial Cards (purist.design/library/radial-fan) — cards fanned on an arc, active one upright; adaptable to client tile view
- Cascading Slider (purist.design/library/cascading-slider) — one wide slide middle, rest wait and swell as they arrive; great for proposal carousel
- Avatar Group Hover (purist.design/library/avatar-group-hover) — neighbours lift with hovered one, distance-based; for client avatars in dashboard
- Card Tilt (purist.design/library/card-tilt) — card leans toward pointer with glare; hover feedback on KPI cards
- Modal Open/Close (purist.design/library/modal-open-close) — dialog eases up and steps back; for client detail panels
- Dropdown Menu (purist.design/library/menu-dropdown) — menu grows out of its corner; for action menus
- Tooltip Open/Close (purist.design/library/tooltip-open-close) — hint appears after a beat and leaves at once; form field hints
- Toast Notice (purist.design/library/toast-open-close) — notice rises in through blur and slips away; inline success messages
- Price Switcher (purist.design/library/price-switcher) — monthly to yearly roll; for plan toggles in billing section
- Sliding Tabs (purist.design/library/tabs-sliding) — highlight slides to active tab; nav tab alternative

## Code or install snippets
- Each component shows “Code” tab with HTML + CSS + React source
- Sign-in required to copy; can also view via MCP call
- Example pattern: `<div class="price-switcher">...</div>` with CSS keyframes for the roll animation
- `<motion.toast>`-style pattern: exit with `blur` + `slip away` transition

## Skip
- Components tied to specific design tools (Figma/Framer compare pages)
- AI-focused streaming text (reasoning stream, reasoning stream) not dashboard-relevant
- Some niche micro-interactions (confetti button, spinning counter) for pure delight, not core dashboard needs
