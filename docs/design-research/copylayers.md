# CopyLayers (https://copylayers.com/library?access=free)

## What it is (2-3 lines)
Curated library of "next-generation templates for AI" — copy-paste prompts that generate production-ready web interfaces when fed to AI coding agents (Claude, Cursor, v0, Bolt, Lovable). Assets are filterable by: Free/Premium, style, AI tool target. Each asset = prompt + expected output preview. Built for people who ship with AI.

## Free or paid (what is free, license if stated)
Free tier: Filter `access=free` shows ~100+ free assets (prompts, templates, components, sections, animations, 3D scenes, backgrounds). Premium: Full library access via subscription (pricing at copylayers.com/pricing). License: Free assets can be used in personal/commercial projects. Premium assets require active subscription.

## Steal for CotizaIA (5-10 bullets: concrete, named pieces usable in a dashboard: nav/sidebar, KPI cards, tables, empty states, CTAs, forms, toasts, command palettes, motion recipes with durations/easings if given. Each bullet with a direct URL when one exists)
- **Dashboard layout prompts** — Search library for "dashboard", "admin panel", "SaaS dashboard". Free assets include full-page layouts with sidebar, top bar, content grid.
- **KPI card sections** — Prompts for metric grids with trend indicators, loading skeletons, dark/light variants. Filter by "components" + "free".
- **Data table / list views** — Prompts for sortable, filterable tables with row actions, pagination, empty states. Filter by "sections" + "table".
- **Command palette / search interface** — Prompts for ⌘K launcher with recent, shortcuts, grouped results. Filter by "components" + "command".
- **Form wizards / multi-step flows** — Prompts for guided forms (quote builder, client onboarding) with progress stepper, validation, autosave. Filter by "templates" + "form".
- **Toast / notification systems** — Prompts for toast stacks, snackbars, alert banners with action buttons, auto-dismiss timers. Filter by "components" + "toast".
- **Theme switcher components** — Prompts for system-aware dark/light toggle with smooth CSS variable transitions, persisted localStorage. Filter by "components" + "theme".
- **Animation / motion presets** — Prompts for Framer Motion / Motion.dev patterns: stagger children (0.1s), page transitions (200ms), hover lift (spring), focus rings. Filter by "animations" + "free".
- **Empty state illustrations + CTAs** — Prompts for friendly empty states with SVG illustrations, primary action, helpful copy. Filter by "components" + "empty".
- **Avatar stacks / user menus / dropdowns** — Prompts for overlapping avatars, user dropdown with keyboard nav, role badges. Filter by "components" + "avatar".

## Code or install snippets (only if the site shows copyable code or an npm package; paste the exact snippet, max 3)
- No direct code snippets on the library page — each asset is a **prompt** you copy into your AI agent. Example prompt structure (from "How it works"):
```
Copy the prompt → Paste into Claude/Cursor/v0/Bolt → Get production code
```
- No npm package. Integration is via prompt copy-paste or Skillry skills (some CopyLayers assets are packaged as Skillry skills).

## Skip (what does not fit a dashboard, 1-3 bullets)
- Landing page / marketing templates (hero, features, pricing, testimonials, footer) — not dashboard UI.
- Full website templates (multi-page sites, blogs, portfolios) — CotizaIA is a single-page app dashboard.
- 3D scenes / backgrounds / shader effects — decorative, not functional dashboard patterns.
- Assets targeting specific AI tools (e.g., "v0 only", "Bolt only") if your workflow uses a different agent.
