# Componentry (https://componentry.dev/)

## What it is
A component library of 53 animated React UI components built for polished interfaces, installable via the shadcn CLI or AI editors with MCP. Each component has editable source code and focuses on smooth motion and interaction.

## Free or paid
Free. Backed by the Vercel OSS Program, MIT-licensed and open source. Components can be added with `npx shadcn@latest add @componentry/<name>`.

## Steal for CotizaIA
- Magnetic Dock sidebar (componentry.dev/docs/components/magnetic-dock) — elegant slide-out nav with hover preview
- Animated Gradient KPI cards (componentry.dev/docs/components/animated-gradient) — colorful background transitions for metric cards
- Hover Transition effects for table rows (componentry.dev/docs/components/hover-transition) — lift/shadow on row hover
- Image Ripple Effect on CTA buttons (componentry.dev/docs/components/image-ripple-effect) — subtle ripple on click
- Magnetic Lines for form fields (componentry.dev/docs/components/magnet-lines) — input fields guided by magnetic pull
- Liquid Chrome inputs with animated focus states
- Empty state illustrations with gentle float motion
- Staggered Card Stack on dashboard load (componentry.dev/docs/components/orbit-card-stack)

## Code or install snippets
- `npx shadcn@latest add @componentry/magnetic-dock`
- `npx shadcn@latest add @componentry/hover-transition`
- Import example: `@componentry/magnetic-dock` — full source available on each component page

## Skip
- WebGL Liquid (too graphical, not dashboard-appropriate)
- Matrix Rain (purely decorative, no UI purpose)
- Flight Status Card (transport-specific, not general dashboard)
