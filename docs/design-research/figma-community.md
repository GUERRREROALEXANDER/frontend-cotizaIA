# Figma Community (https://www.figma.com/community/search?resource_type=mixed&sort_by=relevancy&query=dashboard&editor_type=all&price=free)

## What it is (2-3 lines)
Figma's official community marketplace for free and paid design resources. The search URL filters for free dashboard/admin UI kits. This is a primary source for production-ready dashboard designs, design systems, and component libraries that can be directly inspected, copied, or exported to code.

## Free or paid (what is free, license if stated)
Free tier: All resources returned by `price=free` filter are free to duplicate and use. License varies by creator — most are "Community" license (free for personal/commercial use, attribution appreciated). Some creators restrict redistribution of the .fig file itself.

## Steal for CotizaIA (5-10 bullets: concrete, named pieces usable in a dashboard: nav/sidebar, KPI cards, tables, empty states, CTAs, forms, toasts, command palettes, motion recipes with durations/easings if given. Each bullet with a direct URL when one exists)
- **Responsive sidebar navigation** — Collapsible rail with icon-only/expanded states, active route indicators, nested menus. Search "Sidebar" or "Navigation" in results.
- **KPI metric cards** — Grid of stat cards with trend sparklines, comparison badges (↑12% vs last month), loading skeletons. Search "Dashboard stats" or "KPI cards".
- **Data tables with inline actions** — Sortable, filterable, paginated tables with row selection, bulk actions toolbar, expandable rows for details. Search "Data table" or "Admin table".
- **Empty states with illustrated CTAs** — Friendly illustrations + primary action button (e.g., "Create your first quote"), secondary ghost link. Search "Empty state dashboard".
- **Command palette (⌘K)** — Searchable action launcher with keyboard shortcuts, recent items, grouped categories. Search "Command palette" or "Spotlight search".
- **Toast/notification system** — Top-right stack, progress-bar auto-dismiss, action buttons (Undo, View), success/warning/error variants. Search "Toast notifications" or "Alert system".
- **Form layouts with validation** — Multi-step wizards, inline validation messages, dependent fields, autosave indicators. Search "Form wizard" or "Settings form".
- **Dark/light theme toggle** — System-aware, persisted preference, smooth CSS variable transition (200ms ease-out). Search "Theme switcher" or "Dark mode dashboard".
- **Avatar stacks & user menus** — Overlapping avatars with count badge, dropdown with profile/settings/sign-out, keyboard accessible. Search "User menu" or "Avatar group".
- **Breadcrumb + page header pattern** — Title, description, secondary actions (Export, Filter), breadcrumb trail with truncated segments. Search "Page header dashboard".

## Code or install snippets (only if the site shows copyable code or an npm package; paste the exact snippet, max 3)
- None directly on Figma Community — designs are .fig files. Use Figma plugins (Anima, Locofy, Builder.io) or Dev Mode to export React/Tailwind code.

## Skip (what does not fit a dashboard, 1-3 bullets)
- Landing page hero sections, marketing pages, mobile app screens, presentation decks — not dashboard UI.
- Resources requiring paid Figma Pro/Org features (dev handoff tokens, branching) if team is on free plan.
- Kits built for other frameworks (Flutter, SwiftUI, HTML/CSS only) without React/Tailwind export path.
