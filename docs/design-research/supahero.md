# Supahero (https://supahero.io/)
## What it is (2-3 lines)
Curated library of 1000+ website hero sections (now part of screensdesign.com). Each hero shows a screenshot, name, and links to a detail page. Categories span SaaS, AI, portfolio, e-commerce, agency, dev tools. Massive visual reference for above-the-fold patterns.

## Free or paid (what is free, license if stated)
Free to browse. Redirects to screensdesign.com ("the biggest UX app library in the world"). No license stated; screenshots for inspiration only.
