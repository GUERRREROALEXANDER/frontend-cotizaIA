# Footer Design (https://www.footer.design/)
## What it is (2-3 lines)
A curated gallery of website footers ("the only footer gallery on earth") with 65+ pages of entries filterable by style. A passion project by Benten Woodring, Devin Fountain, and Matt Cram (NOOON Studio); it is inspiration only, not a component library.
## Free or paid (what is free, license if stated)
Free to browse. No license stated on the fetched pages (see https://www.footer.design/info); entries link out to the original sites. No pricing or code license is offered.
## Steal for CotizaIA (5-10 bullets: concrete, named pieces usable in a dashboard: nav/sidebar, KPI cards, tables, empty states, CTAs, forms, toasts, command palettes, motion recipes with durations/easings if given. Each bullet with a direct URL when one exists)
- Dark-style footer pattern (filter: Dark) for the CotizaIA dashboard bottom bar / settings-page footer in dark theme: https://www.footer.design/styles/dark
- Large-type footer pattern (filter: Large Type) for an oversized agency wordmark on the public proposal view: https://www.footer.design/styles/large-type
- Grid footer pattern (filter: Grid) for the proposal PDF footer (agency columns: contact / services / legal): https://www.footer.design/styles/grid
- Small-type utility footer pattern (filter: Small Type) for dense dashboard meta rows (version, status, support link): https://www.footer.design/styles/small-type
- Cards footer pattern (filter: Cards) for a quote-summary card + CTA card pair at the bottom of proposals: https://www.footer.design/styles/cards
- Animated footer pattern (filter: Animated) for subtle footer motion study (keep it minimal in-app): https://www.footer.design/styles/animated
- Browse-all index (65 pages of entries) for quick comparative review of footer density before designing the proposal footer: https://www.footer.design/browse
- No motion recipes with durations/easings were published on the fetched pages, so no motion values are copied here.
## Code or install snippets (only if the site shows copyable code or an npm package; paste the exact snippet, max 3)
None — the site publishes screenshots and style filters, no copyable code or npm package.
## Skip (what does not fit a dashboard, 1-3 bullets)
- Illustrative/bright showpiece footers — heavy illustration and bright marketing styling distract inside an app shell.
- Treating gallery screenshots as drop-in components — they are third-party site captures; adapt the layout idea, not the artwork.
