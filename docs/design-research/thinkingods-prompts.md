# Thinking Gods (https://thinkingods.com/prompts)

## What it is
A prompt library of 9 free prompts + paid ebook ($29 one-time) that “make websites move.” Each prompt carries geometry, motion, and numbers — copy-paste into Claude, Cursor, or v0. Built on real client project work.

## Free or paid
Free: 9 prompts are free to copy (library is free while young). Paid: The design ebook is $49 ($29 introductory one-time) with 95 pages, templates, and future editions free.

## Steal for CotizaIA
- Interactive Heroes prompt (thinkingods.com/prompts) — hand-tracked hero section, adaptable to dashboard hero
- Liquid Buttons prompt (thinkingods.com/prompts) — animated liquid-style buttons for CTAs
- Scroll Key glass keycap with bevelled edges (thinkingods.com/prompts) — numeric input interaction for KPI adjustment
- Card Folder — slide-down face with iridescent gradient reveal for accordion-style expand
- Particle Cloak — pointer-parted particle field to hide/reveal content behind it
- Glow Ring Button — iridescent ring orbiting a pill button for primary CTA
- Send Hello form — paper plane lift-off on submit, field collapse, button tick on form send

## Code or install snippets
- No npm install needed — prompts are copy-pasted into AI generators (Claude/Cursor/v0)
- Each prompt page has “Copy the prompt” button; output is a single self-contained file
- Example structure: geometry + numbers + motion description in a single block

## Skip
- Paid ebook sales page and templates (not UI components)
- Some prompts too experimental (e.g., full site builds vs. dashboard components)
- MediaPipe hand-tracking (requires camera, not web dashboard)
