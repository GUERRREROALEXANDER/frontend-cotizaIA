# Navbar Gallery (https://www.navbar.gallery/)
## What it is (2-3 lines)
A curated, navigation-only design inspiration gallery (550+ entries) with screenshots, per-entry pages, and browsing by nav type. Created by Christina Liubynska after the footer.design model, it exists purely as reference — no components or code are sold.
## Free or paid (what is free, license if stated)
Free to browse. No license stated on the fetched pages; entries link out to the original sites (screenshots only, no reusable code license). Sponsored by Mobbin; a newsletter subscribe is optional.
